# Employee Management Portal

This is a full-stack enterprise-style employee management portal built with the MERN stack (MongoDB, Express, React, Node.js) and designed for scalability and modern development practices.

The project is organized as a monorepo with separate `frontend` and `backend` directories.

## Project Structure

```
employee-management-portal/
├── backend/
│   ├── package.json
│   └── ... (controllers, models, routes, services)
├── frontend/
│   ├── package.json
│   └── src/
└── README.md
```

*   **`frontend/`**: A React application built with Vite, using Redux Toolkit for state management and a modern UI.
*   **`backend/`**: A Node.js and Express server designed to provide a RESTful API for the frontend. (Planned/In-progress)

## Features

The frontend application currently includes a polished UI for:

*   **Dashboard**: At-a-glance overview of company statistics.
*   **Employee Directory**: A searchable and filterable directory of all employees.
*   **Leave Management**: A system for employees to request leave and for managers to approve or deny requests.
*   **Announcements**: A section for posting company-wide announcements.

## Getting Started

To get the project running locally, you will need to set up both the frontend and backend services.

### Frontend

Navigate to the frontend directory and follow the instructions in its README file:

```bash
cd frontend
npm install
npm run dev
```

Instructions for the backend will be added once the initial setup is complete.
